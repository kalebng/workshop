## Lebbie reference

At the start of every session:
1. Read LEBBIE.md (ID card) at the repo root. Then read GEOMETRY.md and DECISIONS.md at the paths it lists.
2. Read the reference version named on the ID card:
   https://raw.githubusercontent.com/kalebng/workshop/v[VERSION]/ref.md
3. Read the latest reference only to check for changes:
   https://raw.githubusercontent.com/kalebng/workshop/main/ref.md

Stop and tell Kaleb before doing any work if:
- LEBBIE.md is missing from the root, a file it lists is missing at that path, or any of them is unreadable or contradicts itself
- A task would go against GEOMETRY.md (propose it first)
- Either reference link can't be read (never work from memory of the rules)
- The latest version is newer than the adopted version (report what changed; don't apply it)

Rules:
- Follow only the modules on the ID card, at the adopted version.
- Adopted rules override this repo unless the ID card lists an approved exception.
- Never change the reference from this repo. Propose exceptions or reference changes to Kaleb; don't apply them yourself.
- Ask before executing. Work on branches; Kaleb merges.
